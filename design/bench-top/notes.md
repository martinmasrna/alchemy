# bench-top — round 1

Axis: where the tap-tap-result loop lives.
Locked: palette, type system, content, mechanics, 3-column grid, chips for named targets, squares for unknowns.
Varied: a workbench pinned above the grid. Two slots plus a result slot in one row. The discovery unfolds *inside* the bench (name, blurb, credit) and stays until the next pick, so there is no dismiss. Hint buttons appear in the same space while a card is held. A dud turns the result slot red for a beat and shakes the bench.
Cost: the bench takes ~150px of the screen permanently, ~230px while a discovery is open, pushing the grid down.
